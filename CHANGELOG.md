# Changelog: X-Phage Engine Evolution

All notable changes to the **X-Phage** project from its genesis to the current **Omni-God Edition (v3.0.1)** are documented below.

---

## [3.0.1] - 2026-02-12 (Current: Omni-God Edition)
### Added
- **Quantum Threading**: Multi-threaded parallel processing for high-load tasks.
- **Chronos Sync**: Real-time hardware clock synchronization for zero-latency streaming.
- **Ether Protocol**: Direct decentralized cloud uplink for remote data relay.
- **Vortex Wipe**: Instant memory purging (Blackhole Protocol) for absolute session security.
- **Omni Panic System**: Detailed security violation reporting for `atom` mutation attempts.

## [3.0.0] - 2026-02-05 (Singularity Upgrade)
### Added
- **Hardware Bypass**: Kernel-level direct hardware access for **StreamX Ultra**.
- **Full ALU Core**: Native support for complex arithmetic (`+`, `-`, `*`, `/`).
- **Matrix Buffer**: High-speed data structures for 192kHz audio and 4K video streams.

## [2.1.0] - 2026-01-20 (Ghost Memory Update)
### Added
- **Ghost Memory Protocol**: Introduced `shadow` for mutable memory and `atom` for strict immutability.
- **Neural Gating**: Advanced `scan` logic for subscription and security checks.

## [1.3.0] - 2026-01-05 (Genesis Expansion)
### Added
- **Library Linking**: Support for `~link` to include `.xh` header files.
- **System Identity**: Global versioning system and optimized build script (`build.sh`).

## [1.0.0] - 2025-12-15 (The Beginning)
### Added
- **Core Architecture**: Initial release of the Lexer and Runtime.
- **Basic Keywords**: `pulse`, `atom`, `beam`.
